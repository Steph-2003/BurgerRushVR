# BurgerRushVR

I am Steph Araujo and i am the sole developer of this game.
---------------------------------------------------------------
BurgerRushVR is a Virtual Reality game and fast-paced simulator that places the player in the shoes of a fast-food restaurant worker. The player is tasked with fulfilling customer orders using a VR Tray System, selecting and assembling items like burgers, fries, nuggets, and drinks. Each order must be completed accurately and within a limited amount of time. Speed, precision, and memory are essential to maximize performance. Successfully completing orders will give the player points, while incomplete orders will result in the loss of points eventually leading to the game over. This game not only requires you to be precise you also have to be quick! Are you up for the challenge?
